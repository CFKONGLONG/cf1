# 猜数字小游戏 (Guess Number)

一个用 Python 写的命令行小游戏。电脑随机生成一个 1-100 的整数，玩家输入猜测，程序提示“大了”或“小了”，直到猜中并统计猜测次数。

## 功能特点
- 电脑随机生成 1-100 的整数
- 实时提示“大了”、“小了”
- 猜中后自动显示答案和总猜测次数
- 对非数字输入做了简单校验

## 运行环境
- Python 3.x
- 无需安装第三方库（仅使用标准库 `random`）
